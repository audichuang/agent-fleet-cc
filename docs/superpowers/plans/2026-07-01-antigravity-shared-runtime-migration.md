## GOAL

Replace antigravity's self-contained job runtime (`lib/state.mjs` flat `state.json` index + `lib/atomic-state.mjs` in-process mutex + `lib/job-control.mjs` snapshot/health-classifier/reconcile + `lib/job-helpers.mjs` foreground/background glue + `lib/poll.mjs` + `lib/liveness.mjs` + `commands/_worker.mjs` + `commands/_watchdog.mjs`) with the repo's vendored shared runtime (`shared/lib/` → `plugins/antigravity/scripts/lib/shared/`), exactly following how `cc` migrated (v0.3.0): a ~120-line `lib/adapter.mjs` owns all agy engine knowledge, a 34-line `worker-entry.mjs` drives `runWorker` off-process for background jobs, and every command calls the shared state-store / reconcile / wait / cancel / events APIs against the directory-per-job + `events.ndjson` + O_EXCL CAS layout. This is a **hardening upgrade** (shared adds TTL-based stale-claim detection, recycled-pid + empty-lock semantics, claim-owner orphan judgment that no longer over-reclaims on worker-pid death, and an orphan-lock sweep — none of which antigravity's runtime has; verified `reconcile.mjs:47-90`, `state-store.mjs:196-215` vs `state.mjs:130-158,361-413`), sequenced bottom-up so the suite stays green at every commit except one explicitly-marked red-until-next window.

## BEHAVIOR CHANGES (call out in CHANGELOG + PR)

1. **OAuth becomes fail-with-hint, not pause-and-surface (HARD FACT 5, intentional).** `runWorker` is one-shot: it writes stdin, `stdin.end()`s (`worker.mjs:196-197`), and runs to close — it has no ability to detect an OAuth URL mid-run, pause, and resume. The current `runAgyPrint` OAuth-URL scraping (`agent-runtime.mjs:150-160`) + `healthStatus:"auth_required"` + `oauthUrl` surfacing (`job-helpers.mjs:46-53`) is **removed**. Post-migration an unauthenticated agy exits non-zero; the adapter's `classifyError` returns `"auth"`; the job finalizes `failed` with `errorKind:"auth"`; the command layer detects `errorKind==="auth"` and prints the hint to run `/antigravity:setup` and retry. The `oauthUrl` field disappears from the schema.
   - **Auth-channel handling (the cross-cutting blocker — every panel flagged it):** the old code scraped auth sentinels from **stdout** (`agent-runtime.mjs:150-160`), but `runWorker` passes only `outcome.stderrTail` to `classifyError` (`worker.mjs:259`). I ran real agy live — it is authenticated in this environment, so **which channel an unauthenticated agy uses is NOT verifiable here** (see "Cannot be verified"). To be correct regardless of channel, the adapter detects auth on **both**: `classifyError` matches the auth regex against `stderrTail` (its only input), AND `extractResult` inspects the joined stdout tail for the same sentinels and returns `ok:false` when found — so an unauthenticated agy that prints its prompt to stdout and exits 0 finalizes `failed` (not a silent wrong-success), and one that exits nonzero on stderr gets `errorKind:"auth"`. Both are adapter-local (no shared edit).
2. **Print-mode content is accumulated as events, then joined (HARD FACT 3 + spec D-1).** cc's `parseEvent` returns `null` for content and only emits on JSON `session`/`result` (`adapter.mjs:66-98`); agy emits plain text with no JSON stream (verified live: `agy --print "..." → "OK\n"`, exit 0, empty stderr, agy v1.0.14). The agy adapter's `parseEvent` emits one `{kind:"line",text}` event per line **including blank lines** (`worker.mjs:203-219` pushes every non-null); `extractResult` joins with `\n` then trims only leading/trailing whitespace. **Fidelity (spec D-1, corrected from the panel's lossy draft):** emitting all lines means inner blank lines (paragraph breaks) are **preserved losslessly** in `resultText` — required so `parseReviewJson`/`IMAGE_PATH` and multi-paragraph answers survive. The `log` file is NOT byte-exact (readline re-joins `line+"\n"`), so `resultText` is the fidelity source, not the log. A Phase-1 test asserts a multi-paragraph fixture keeps its inner blank lines.
3. **Empty-stdout-on-exit-0 = completed with `resultText:null`, NOT failed (blocker).** `extractResult` returns `ok:(exitCode===0)`; `worker.mjs:244-248` sets `failed = ...|| exitCode!==0 || !result.ok`, so a genuine clean-but-silent agy run finalizes `completed` with `resultText:null`. `renderResultOutput` (`render.mjs:324-335`) then falls through to "No captured result payload was stored" — this is the intended UX, locked with a test, not a regression.
4. **No sessionId capture (HARD FACT 4).** agy print-mode exposes no conversation id, so `extractResult.sessionId` is always `null`; `resumeArgs` is contract-only (unused by the runtime). Resume stays a command-layer concern via `--continue`/`--conversation <id>` flowing through `job.request.mode`. `render.mjs:317-322` `formatResumeHint(null)` ("Resume the most recent agy conversation: `agy --continue`") becomes the only branch — preserved.
5. **Health/heartbeat/watchdog machinery removed.** `classifyRuntimeHealth`/`enrichJob` health fields (`job-control.mjs:79-175`), `lastProgressAt`/`lastHeartbeatAt`/`healthStatus`/`possibly_stalled`/`quiet`, `liveness.mjs`, and `_watchdog.mjs` are replaced by shared reconcile-per-poll (`wait.mjs:34`) + `reconcileDeadPids` on every status/result. Status rendering drops the Health section fields. Net liveness is equal-or-better (shared adds TTL + orphan sweep).
6. **`ANTIGRAVITY_PLUGIN_SESSION_ID` job filtering is PRESERVED (spec D-14 — corrected from the panel's "drop" draft; codex review must-fix #3).** Shared keys jobs by workspace dir, but the shared job schema already has a top-level `sessionId` field (`shared/lib/core/job.mjs:39`), and agy's engine resume sessionId is always null (HARD FACT 4) so it does not occupy that field. **Decision: KEEP it** — store the host session id in top-level `sessionId` (where the existing `filterJobsForCurrentSession` already reads it, `job-control.mjs:29-32`, and creation already writes it, `job-helpers.mjs:86-94`); the filter runs unchanged over `listJobs`. Multi-session isolation is preserved (NOT a behavior change). Dropping it would silently break session isolation.
7. **Recursion guard is ADDED (spec D-15 — new protection).** `grep` over `plugins/antigravity/scripts` + `bin` finds **no read-side** of any recursion marker today (antigravity currently has NO guard). `buildEngineEnv` force-injects the marker (`env.mjs:32`); **Decision: name it `ANTIGRAVITY_ACTIVE` and ADD a read-side guard at the CLI entry `bin/antigravity.mjs`, mirroring cc's `cc-companion.mjs:91`** — an agy-in-agy invocation is refused. This is a small new safety improvement (not a behavior change to existing flows), consistent with cc.

## DATA-INTEGRITY DECISIONS (legacy flat-state jobs)

**Documented clean break for the JOB store; config is one-time-migrated (D-6); no data relocation.**
- **Layout is disjoint on disk.** Old: `<stateDir>/state.json` index + `jobs/<id>.json` + `jobs/<id>.log` + `jobs/<id>.lock` (`state.mjs:5-11,71-81`). New: `<stateDir>/jobs/<id>/{job.json,prompt.txt,events.ndjson,log,terminal.lock}` (`state-store.mjs:12-26`). Shared `listJobs` reads `jobs/<name>/job.json` (`state-store.mjs:76`); an old `jobs/<id>.json` file is where shared expects a *directory*, so `readJob` returns `null` and old jobs are silently invisible — never resurrected, never crash a read (`readJob` try/catches, `listJobs` skips falsy: `state-store.mjs:59-65,77`).
- **`stateDir` keying is preserved VERBATIM (DATA-ROOT blocker) so the workspace dir does not move** — only the sub-layout changes. The adapter reproduces `state.mjs:50-61` exactly: root = `CLAUDE_PLUGIN_DATA + "/state"` else `os.tmpdir()/antigravity`; workspace = `slugify(basename(gitRoot))` + `sha256(gitRoot).slice(0,12)` (**12-hex, not cc's 8-hex/home-based root**), gitRoot via `resolveWorkspaceRoot`. Do NOT adopt cc's `~/.claude/plugins/data` fallback — that would relocate every non-`CLAUDE_PLUGIN_DATA` install and strand all jobs, turning the intra-dir clean break into a double-relocation.
- **In-flight ≤0.2.0 background jobs** keep running as detached agy processes but become untracked (their old `_worker.mjs` still writes old-layout files; new commands ignore them). No auto-delete of old files. **CHANGELOG states:** "0.3.0 changes the on-disk job layout; jobs started under ≤0.2.0 are not visible to 0.3.0 commands — let them finish or cancel before upgrading. The old `state.json` job index is inert; its `config` block is migrated once into `config.json` (D-6) before the file may be deleted."
- **Config is MIGRATED, not clean-broken (D-6 / codex must-fix M2).** `lib/agy-config.mjs` reads `<stateDir>/config.json`; if absent while a legacy `state.json` exists, it seeds `stopReviewGate` from `state.json.config` ONE time. The `getConfig`/`setConfig` consumers (`job-control.mjs:190`, status) and `commands/setup.mjs`'s write repoint to it. Lands in Phase 4·0, BEFORE `state.mjs` is deleted in Phase 6.

**KEY CODE — `lib/adapter.mjs` (real, verified against live agy + `state.mjs:28-61` + `agent-runtime.mjs:27-45,52-93`):**
```js
// plugins/antigravity/scripts/lib/adapter.mjs
// AntigravityAdapter: all agy engine knowledge lives here (spec §2/§5).
// Job runtime (state/worker/cancel/reconcile) is the vendored shared lib.
// agy --print is PLAIN-TEXT print mode: NO JSON event stream (verified live,
// agy v1.0.14: `agy --print "<prompt>"` → "OK\n", exit 0, empty stderr).
// parseEvent therefore emits one event per line INCLUDING blank lines (so
// paragraph breaks survive — spec D-1) and extractResult joins + edge-trims.
// agy exposes no conversation id → sessionId null.
import os from "node:os";
import path from "node:path";
import { createHash } from "node:crypto";
import { spawn } from "node:child_process";
import { existsSync } from "node:fs";
import { resolveWorkspaceRoot } from "./workspace.mjs";

// Recursion marker (spec D-15). buildEngineEnv force-injects it; a read-side
// guard is ADDED at the CLI entry (bin/antigravity.mjs), mirroring cc's
// cc-companion.mjs:91, so an agy-in-agy recursion is refused. New protection
// (antigravity had NO read-side before — grep-verified).
export const RECURSION_MARKER = "ANTIGRAVITY_ACTIVE";
export const DEFAULT_AGY_BIN = "agy";
export const DEFAULT_PRINT_TIMEOUT_MS = 300000; // agy print-mode default 5m (agent-runtime.mjs:19)

// --- state root (ported VERBATIM from state.mjs:50-61 — DO NOT relocate) ---
function stateRootDir(env = process.env) {
  return env.CLAUDE_PLUGIN_DATA
    ? path.join(env.CLAUDE_PLUGIN_DATA, "state")
    : path.join(os.tmpdir(), "antigravity");
}
function slugify(v) {
  return String(v ?? "").replace(/[^A-Za-z0-9._-]/g, "-").replace(/-+/g, "-")
    .replace(/^-|-$/g, "").slice(0, 48);
}
// resolveDataRoot returns the ROOT (…/state or os.tmpdir()/antigravity);
// workspaceStateDir(dataRoot, cwd) appends "<slug>-<12hex sha256(gitRoot)>".
export function resolveDataRoot(env = process.env) {
  return stateRootDir(env);
}
export function workspaceStateDir(dataRoot, cwd) {
  const root = resolveWorkspaceRoot(cwd);
  const hash = createHash("sha256").update(root).digest("hex").slice(0, 12);
  return path.join(dataRoot, `${slugify(path.basename(root))}-${hash}`);
}

export function resolveAgyBin(env = process.env) {
  if (env.AGY_BIN && existsSync(env.AGY_BIN)) return env.AGY_BIN;
  for (const dir of (env.PATH || env.Path || "").split(":").filter(Boolean)) {
    if (existsSync(path.join(dir, DEFAULT_AGY_BIN))) return path.join(dir, DEFAULT_AGY_BIN);
  }
  if (env.HOME && existsSync(path.join(env.HOME, ".local", "bin", DEFAULT_AGY_BIN)))
    return path.join(env.HOME, ".local", "bin", DEFAULT_AGY_BIN);
  return DEFAULT_AGY_BIN;
}
export function resolveAgyTimeouts(env = process.env) {
  const p = Number(env.AGY_PRINT_TIMEOUT_MS);
  const printMs = Number.isFinite(p) && p > 0 ? p : DEFAULT_PRINT_TIMEOUT_MS;
  const h = Number(env.AGY_JOB_TIMEOUT_MS);
  const rawHard = Number.isFinite(h) && h > 0 ? h : printMs + 60000;
  // D-19 invariant: the Node backstop must NEVER fire before agy's own
  // --print-timeout (let the engine time out first with a clean error).
  const hardMs = Math.max(rawHard, printMs);
  return { printMs, hardMs };
}
export async function probeAgy({ bin = resolveAgyBin(), timeoutMs = 5000 } = {}) {
  return new Promise((resolve) => {
    const child = spawn(bin, ["--version"], { stdio: ["ignore", "pipe", "pipe"] });
    let stdout = "";
    const timer = setTimeout(() => { child.kill("SIGTERM"); resolve({ ok: false, reason: "timeout" }); }, timeoutMs);
    child.stdout.on("data", (c) => (stdout += c.toString("utf8")));
    child.on("error", (e) => { clearTimeout(timer); resolve({ ok: false, reason: e.code === "ENOENT" ? "not-installed" : e.message }); });
    child.on("exit", (code) => { clearTimeout(timer); code !== 0 ? resolve({ ok: false, reason: `exit ${code}` }) : resolve({ ok: true, version: stdout.trim().split(/\s+/)[0] || "unknown" }); });
  });
}
function toGoDuration(ms) { return `${Math.max(1, Math.ceil(Number(ms) / 1000))}s`; }

// Auth sentinels the old runtime scraped (agent-runtime.mjs:41-45) + the URL.
// Checked on BOTH channels: stderrTail (classifyError) and joined stdout tail
// (extractResult) — see BEHAVIOR CHANGE 1's auth-channel note.
const AUTH_PATTERN =
  /Authentication required|Waiting for authentication|accounts\.google\.com\/o\/oauth2\/auth|not (?:authenticated|logged in)|unauthorized|\b401\b/i;

export function makeAntigravityAdapter({ env = process.env } = {}) {
  const bin = resolveAgyBin(env);
  const { printMs } = resolveAgyTimeouts(env);
  return {
    name: "antigravity",
    engine: "antigravity",
    recursionMarker: RECURSION_MARKER,
    wantsWatchdog: false,
    // Prompt is an argv OPERAND of --print (verified live: bare `agy --print`
    // exits 2 "flag needs an argument: -print"; `agy --print "<prompt>"` → OK).
    // stdinPayload:"" — agy stdio never reads the prompt from stdin
    // (agent-runtime.mjs:135,140); runWorker's stdin.end()+EPIPE-on-exit-0
    // guard (worker.mjs:243) makes the empty closed stdin harmless.
    buildInvocation({ job, prompt }) {
      const r = job.request ?? {};
      const argv = [r.binaryArgv ? undefined : bin, ...(r.binaryArgv ?? [])].filter(Boolean);
      if (r.mode === "continue") argv.push("--continue");
      if (r.mode === "conversation") {
        if (!r.conversationId) throw new Error("antigravity: mode=conversation requires conversationId");
        argv.push("--conversation", String(r.conversationId));
      }
      if (r.model) argv.push("--model", String(r.model));
      if (r.sandbox) argv.push("--sandbox");
      argv.push("--print-timeout", toGoDuration(r.printTimeoutMs ?? printMs));
      for (const d of r.addDirs ?? []) argv.push("--add-dir", String(d));
      argv.push("--print", prompt);
      return { argv, env: {}, stdinPayload: "" };
    },
    // No event stream — emit ONE event per line INCLUDING blank lines so
    // extractResult can rebuild paragraph structure losslessly (spec D-1).
    // The log is NOT byte-exact (readline re-joins line+"\n"), so resultText —
    // not the log — is the fidelity source. Never throws.
    parseEvent(rawLine) {
      const text = typeof rawLine === "string" ? rawLine : String(rawLine ?? "");
      return { kind: "line", text };
    },
    // Join ALL lines, then trim only leading/trailing whitespace — inner blank
    // lines (paragraph breaks) survive (spec D-1). sessionId always null (HARD
    // FACT 4). ok = exit 0 AND stdout carries no auth sentinel (auth-channel).
    extractResult(events, exitCode) {
      const joined = events.filter((e) => e.kind === "line").map((e) => e.text).join("\n").trim();
      const authInStdout = AUTH_PATTERN.test(joined.slice(-2000));
      return {
        ok: exitCode === 0 && !authInStdout,
        resultText: joined.length ? joined : null,
        sessionId: null,
        usage: null,
      };
    },
    classifyError(stderrTail, exitCode) {
      const s = String(stderrTail ?? "");
      if (AUTH_PATTERN.test(s)) return "auth";
      if (/ENOTFOUND|ECONNREFUSED|ETIMEDOUT|fetch failed|network|ENETUNREACH/i.test(s)) return "endpoint";
      if (exitCode === 127 || /command not found|ENOENT|not found/i.test(s)) return "not-installed";
      return "unknown";
    },
    resumeArgs(sessionId) { return ["--conversation", String(sessionId)]; },
  };
}
```

Note: when `extractResult` flags auth-in-stdout, `result.ok` is false → `worker.mjs:244` sets `failed`, and `classifyError(stderrTail…)` runs on possibly-empty stderr → `unknown`. To keep `errorKind:"auth"` in the stdout-auth case, the command-layer projection (Phase 4) treats "failed + resultText matches AUTH_PATTERN" as auth too (belt-and-suspenders; documented).

const AUTH_RE = /Authentication required|accounts\.google\.com\/o\/oauth2\/auth|not (?:authenticated|logged in)/i;

export function stateDirFor(cwd, env = process.env) {
  return workspaceStateDir(resolveDataRoot(env), cwd);

// Shared job → antigravity-shaped fields the render.mjs helpers expect.
// resultText → result.rawOutput; errorKind==="auth" (or auth-in-text) → auth.
export function projectJob(job) {
  if (!job) return null;
  const authByText = job.status === "failed" && typeof job.resultText === "string" && AUTH_RE.test(job.resultText);
  const errorKind = authByText ? "auth" : (job.errorKind ?? null);
  return {
    ...job,
    kind: job.request?.kind ?? "task",
    conversationId: job.request?.conversationId ?? null,
    threadId: null,
    summary: firstLine(job.resultText),
    errorMessage: job.error ?? null,
    errorKind,
    result: job.resultText != null
      ? { rawOutput: job.resultText, status: job.status, exitCode: job.exitCode ?? null }
      : null,
  };
}
function firstLine(t) {
  if (typeof t !== "string") return null;
  const l = t.split("\n").map((s) => s.trim()).find(Boolean) ?? null;
  return l && l.length > 120 ? `${l.slice(0, 117)}...` : l;
}

function makeRecord({ cwd, kind, title, request, env }) {
  const { printMs, hardMs } = resolveAgyTimeouts(env);
  // D-19 (codex M4): the backstop must never pre-empt agy's own --print-timeout,
  // which buildInvocation derives from request.printTimeoutMs ?? env printMs.
  // Clamp against that EFFECTIVE print timeout, not just env printMs.
  const effPrintMs = Number(request?.printTimeoutMs) > 0 ? Number(request.printTimeoutMs) : printMs;
  const requested = Number(request?.timeoutMs);
  const timeoutMs = Math.max(Number.isFinite(requested) && requested > 0 ? requested : hardMs, effPrintMs);
  const record = createJobRecord({
    engine: "antigravity", title, cwd, timeoutMs,
    request: { ...request, kind },
  });
  // D-14: host session id lives in top-level sessionId (where
  // filterJobsForCurrentSession reads it); agy engine sessionId is always null,
  // so this field is free to carry it. createJobRecord defaults it to null.
  record.sessionId = env.ANTIGRAVITY_PLUGIN_SESSION_ID ?? null;
  return record;
}

// FOREGROUND (rescue/review/adversarial/image + task --foreground)
export async function runForeground({ cwd, kind, title, prompt, request, env = process.env, deps = {} }) {
  const stateDir = stateDirFor(cwd, env);
  const record = makeRecord({ cwd, kind, title, request, env });
  createJob(stateDir, record, prompt);
  pruneJobs(stateDir);
  const forwarder = installCancelForwarder({});
  try {
    await runWorker({ stateDir, jobId: record.id, adapter: makeAntigravityAdapter({ env }),
      deps: { baseEnv: env, onChild: forwarder.onChild, ...deps } });
  } finally { forwarder.dispose(); }
  return { stateDir, job: projectJob(readJob(stateDir, record.id)) };
}

// BACKGROUND (task default, review/rescue --background) — cc F3 sync-throw guard.
export function startBackground({ cwd, kind, title, prompt, request, env = process.env, deps = {} }) {
  const stateDir = stateDirFor(cwd, env);
  const record = makeRecord({ cwd, kind, title, request, env });
  createJob(stateDir, record, prompt);
  pruneJobs(stateDir);
  const workerPath = path.join(path.dirname(fileURLToPath(import.meta.url)), "..", "worker-entry.mjs");
  let child;
  try {
    child = (deps.workerSpawnImpl ?? spawn)(process.execPath, [workerPath, stateDir, record.id],
      { detached: true, stdio: "ignore", env: { ...env } });
  } catch (error) {
    finalizeJob(stateDir, record.id, { status: "failed", error: String(error?.message ?? error), errorKind: "spawn" });
    return { stateDir, job: projectJob(readJob(stateDir, record.id)), failed: true };
  }
  child.unref();
  return { stateDir, job: projectJob(readJob(stateDir, record.id)), failed: false };
}
